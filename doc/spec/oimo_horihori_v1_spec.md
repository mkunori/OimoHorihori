# OIMO HORIHORI v1.0 仕様書

## 1. 概要

### 1.1 タイトル

**OIMO HORIHORI**

### 1.2 ゲームジャンル

スマートフォンブラウザ向けのシンプルな放置ゲーム。

プレイヤーは芋を自動生産し、貯めた芋を使って畑をレベルアップする。
畑のレベルを上げることで、1秒あたりの芋生産量が増えていく。

初期版では複雑な育成システム、転生、ガチャ、ミッション、戦闘などは実装しない。

### 1.3 基本コンセプト

```text
芋を掘る
↓
芋が自動で増える
↓
芋を使って畑をレベルアップする
↓
1秒あたりの芋生産量が増える
↓
さらに芋が増える
```

ゲームの中心は、

**「芋を増やす・畑を育てる・数字を見る」**

という非常にシンプルなループとする。

## 2. 対応環境

### 2.1 対応端末

- スマートフォンブラウザを主対象とする
- 縦画面を基本とする
- PCブラウザでもプレイ可能とする

### 2.2 初期版の保存方式

ユーザー登録は行わない。

ブラウザのローカルストレージ等を利用して、端末内にセーブデータを保持する。

将来的には、

- ユーザー登録
- サーバー保存
- 複数端末間のデータ共有
- ランキング

を追加できる設計方針とする。

## 3. 初回起動

初回のみ、ゲーム開始前に「掘る！」ボタンを表示する。

### 3.1 初回画面

```text
OIMO HORIHORI

[ 掘る！ ]
```

### 3.2 「掘る！」ボタン

初回に1回だけ押すことができる。

押した時点で、

- 0.1芋を獲得する
- 自動生産を開始する
- 通常ゲーム画面へ移行する

一度開始した後は、このボタンを再表示しない。

## 4. 芋

ゲーム内の基本資源。

### 4.1 初期生産量

```text
0.1 芋 / 秒
```

初回の「掘る！」操作後、自動的に生産を開始する。

### 4.2 所持芋

現在プレイヤーが使用可能な芋。

畑のレベルアップ時に消費する。

### 4.3 総生産芋

ゲーム開始から現在までに生産した芋の累計。

畑購入などで芋を消費しても減少しない。

将来的に以下へ利用する。

- 総生産量ランキング
- 実績
- アカウントデータ
- その他の進行条件

## 5. 畑

- 畑1
- 畑2
- 畑3

すべてゲーム開始時から画面上に表示する。

芋が不足している場合は購入不可状態として表示する。

## 9. 畑のレベルアップ

### 9.1 購入単位

常に、

```text
+1 Lv
```

のみ。

x10、MAX、自動購入などは初期版では実装しない。

### 9.2 操作方法

専用の「購入」ボタンは配置しない。

**畑カードまたは畑の名前部分そのものをタップすると、1レベル購入する。**

### 9.3 購入可能条件

現在所持している芋が、次のレベルアップコスト以上であること。

芋が足りない場合、

- タップしても購入できない
- 畑カードを暗め・グレー系の表示にする
- 購入可能になると通常表示へ戻る

### 9.4 生産量増加

レベルアップによる生産量増加は固定加算とする。

例：

```text
畑1 Lv.10
0.1 × 10
= 1.0 芋 / 秒
```

一定レベルごとの倍率ボーナスなどは初期版では実装しない。

---

## 10. 畑の価格上昇

各畑のレベルアップコストは、レベルが上がるごとに増加する。

基本倍率は、

```text
1.25倍
```

とする。

計算上発生した端数は、

**常に切り上げる。**

### 10.1 基本式

```text
次回コスト
=
初期コスト × 1.25 ^ 現在レベル
```

計算結果を整数へ切り上げる。

### 10.2 例

畑1の場合：

```text
Lv.0 → Lv.1 : 10芋
Lv.1 → Lv.2 : 13芋
Lv.2 → Lv.3 : 16芋
...
```

---

## 11. 総生産量

現在の1秒あたり総生産量は、

```text
基礎生産
+
畑1の生産量
+
畑2の生産量
+
畑3の生産量
```

とする。

### 基礎生産

```text
0.1 芋 / 秒
```

### 例

```text
基礎生産 : 0.1
畑1 Lv.10 : 1.0
畑2 Lv.2  : 4.0
畑3 Lv.1  : 50.0

合計
55.1 芋 / 秒
```

---

## 12. 数値表示

ゲーム内の主要な数値は、原則として最初から指数表記を使用する。

### 12.1 表示例

```text
1.000e-1
1.000e+0
1.250e+1
1.000e+3
1.234e+5
8.721e+12
```

### 12.2 表示桁

仮数部は基本的に小数点以下3桁とする。

例：

```text
1.234e+5
```

### 12.3 レベル表示

レベルについては指数表記を使用しない。

```text
Lv. 12
```

のように通常の整数で表示する。

---

## 13. オフライン生産

ゲームを閉じている間も芋を生産する。

### 13.1 最大時間

最大、

```text
8時間
```

まで計算する。

### 13.2 生産率

オフライン中も、

```text
現在の芋 / 秒 × 経過秒数
```

をそのまま獲得する。

オフライン生産に減衰は設けない。

### 13.3 最大秒数

```text
8時間 = 28,800秒
```

8時間以上経過していた場合も、8時間分までしか獲得できない。

---

## 15. セーブ

ゲーム状態は自動保存する。

プレイヤーが手動でセーブボタンを押す必要はない。

### 15.1 保存対象

最低限、以下を保存する。

- ゲーム開始済みか
- 現在所持芋
- 総生産芋
- 畑1レベル
- 畑2レベル
- 畑3レベル
- 最終保存時刻
- セーブデータバージョン

### 15.2 自動保存

以下のタイミングを想定する。

- 一定間隔
- 畑レベルアップ時
- 重要な状態変更時

設定画面からセーブデータを初期化できるようにする。

## 17. セーブデータ互換性

ゲームアップデート時は、

**可能な限り既存セーブデータとの互換性を維持する。**

将来、

- 畑4
- 転生
- 実績
- ランキング
- アカウント
- その他の新機能

を追加した場合でも、既存プレイヤーの進行データをできる限り引き継げるようにする。

セーブデータにはバージョン情報を持たせる方針とする。

## 23. 将来の不正対策

初期版は身内数名程度で遊ぶことを想定し、強い不正対策は行わない。

ランキングやアカウント機能追加時には、

- 人間確認
- サーバー側でのランキング登録検証
- 不自然な値のチェック

などを追加する。

ローカルセーブの値をランキング用データとしてそのまま信用しない。

## 25. v1.0 完成条件

以下が動作すれば、OIMO HORIHORI v1.0の完成とする。

1. 初回「掘る！」を1回押してゲームを開始できる
2. 初期状態で0.1芋 / 秒が自動生産される
3. 畑1〜3が最初から表示される
4. 芋が足りる畑をタップすると1レベル購入できる
5. 畑レベルに応じて生産量が固定加算される
6. 畑価格が1.25倍ずつ上昇する
7. 価格端数は切り上げられる
8. 数値が指数表記で表示される
9. 現在芋、生産量、総生産量が表示される
10. セーブデータがブラウザ内に保存される
11. 再起動後もデータをロードできる
12. 最大8時間までオフライン生産できる
13. オフライン復帰時に獲得結果が表示される
14. 設定画面からセーブ初期化できる
15. スマートフォン縦画面で問題なく操作できる
