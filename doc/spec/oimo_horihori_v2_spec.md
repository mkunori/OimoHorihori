# OIMO HORIHORI v2.0.0 仕様書

## 1. 概要

### 1.1 タイトル

**OIMO HORIHORI**

### 1.2 v2.0.0 の目的

v1.0.0 の、

**「芋を増やす・畑を育てる・数字を見る」**

というシンプルなゲーム性を維持しつつ、長期プレイ向けの要素を追加する。

v2.0.0 では主に以下を追加する。

- 畑1〜3の進行バランス再調整
- +10 / MAX 購入
- REPLANT（植え直し / 転生）
- 種芋
- 種芋による恒久強化
- 実績
- 統計
- 共有機能
- いも図鑑

ゲームの核は引き続き、

```text
芋を増やす
↓
畑を育てる
↓
さらに芋を増やす
↓
REPLANTする
↓
恒久強化する
↓
さらに効率よく芋を増やす
```

とする。

# 3. 畑バランス再調整

v2.0.0 では畑1〜3の価格と生産量を以下に変更する。

| 畑 | 初期コスト | 1Lvあたり生産量 | 価格倍率 |
|---|---:|---:|---:|
| 畑1 | `1.000e+1` | `+1.000e-1 / sec` | `×1.25` |
| 畑2 | `3.000e+5` | `+5.000e+0 / sec` | `×1.25` |
| 畑3 | `1.500e+6` | `+5.000e+1 / sec` | `×1.25` |

価格計算時の端数は常に切り上げる。

### 3.1 到達目標

おおよその進行イメージは以下。

```text
1日目
畑1を中心に育成

2日目
畑2へ到達

3日目
畑2を中心に育成

4日目
畑3へ到達
```

実際の到達速度はプレイ頻度やオフライン時間によって前後してよい。

# 4. 購入単位

畑購入に以下の購入モードを追加する。

```text
[ +1 ] [ +10 ] [ MAX ]
```

購入モードは HORIHORI 画面上部に1か所だけ表示する。

各畑カードに個別の購入ボタンは追加しない。

畑カード自体をタップして購入する仕様は維持する。

### 4.1 +1

1Lvのみ購入する。

### 4.2 +10

最大10Lvまで購入する。

所持芋が10Lv分に足りない場合は、

**購入可能な最大Lv数まで購入する。**

例：

```text
+10選択中
7Lv分だけ購入可能
↓
畑カードをタップ
↓
+7Lv
```

### 4.3 MAX

現在の所持芋で購入可能な最大Lv数を一括購入する。

### 4.4 コスト表示

畑カードには、現在選択中の購入モードに応じたコストを表示する。

例：

```text
+1選択
COST 1.250e+4 芋

+10選択
+10 Lv
COST 3.412e+5 芋

MAX選択
MAX +17 Lv
COST 8.221e+5 芋
```

### 4.5 初期状態

ページ再表示時は `+1` を初期選択とする。

# 6. REPLANT

「植え直し」に相当する転生システム。

ゲーム内表記は、

**REPLANT**

とする。

REPLANT は畑3の次に、畑カードと同程度の存在感で HORIHORI 画面内に配置する。

---

# 7. REPLANT の基本仕様

REPLANT すると現在の周回をリセットし、種芋を獲得する。

### 7.1 リセットされるもの

- 現在所持芋
- 畑1レベル
- 畑2レベル
- 畑3レベル
- 現在の周回生産量

### 7.2 維持されるもの

- 総生産芋
- 種芋
- 種芋で購入した恒久強化
- REPLANT 回数
- 実績
- 統計
- 図鑑
- 設定
- その他の永久記録

### 7.3 REPLANT 後

再び初回と同様に、

```text
[ 掘る！ ]
```

を1回押して新しい周回を開始する。

---

# 8. 種芋獲得量

種芋獲得量は、現在の周回生産量を基準に決定する。

### 8.1 基準

```text
種芋1個
1.000e+7 周回生産芋
```

### 8.2 獲得数

獲得予定種芋数 `n` は、

```text
floor(sqrt(周回生産量 / 1.000e+7))
```

を基準とする。

### 8.3 必要周回生産量

| 種芋 | 必要周回生産量 |
|---:|---:|
| 1 | `1.000e+7` |
| 2 | `4.000e+7` |
| 3 | `9.000e+7` |
| 4 | `1.600e+8` |
| 5 | `2.500e+8` |

以降も `1.000e+7 × n²` とする。

### 8.4 REPLANT 可能条件

**最低1個以上の種芋を獲得できる状態でのみ REPLANT 可能。**

種芋0個の状態では REPLANT ボタンを無効化する。

表示例：


```text

[ キャンセル ]
[ REPLANT ]
```

# 10. 種芋

REPLANT によって獲得する恒久資源。

種芋は消費型通貨とする。

種芋を消費して恒久強化を購入する。

---

# 11. 種芋強化

以下の3種類を用意する。

## 11.1 生産力強化

1Lvにつき、

```text
全生産量 +0.5%
```

全生産量とは、

```text
基礎生産
+
畑1生産
+
畑2生産
+
畑3生産
```

の合計。

その合計に対して生産力強化倍率を掛ける。

上限なし。

---

## 11.2 掘り出し強化

1Lvにつき、

```text
基礎生産 +0.1 芋 / sec
```

初期基礎生産は、

```text
0.1 芋 / sec
```

なので、

```text
Lv.1 → 0.2 / sec
Lv.5 → 0.6 / sec
Lv.20 → 2.1 / sec
```

となる。

上限なし。

---

## 11.3 放置強化

1Lvにつき、

```text
オフライン生産上限 +30分
```

初期値は8時間。

最大24時間。

```text
Lv.0  = 8時間
Lv.1  = 8時間30分
Lv.8  = 12時間
Lv.32 = 24時間
```

Lv.32を上限とする。

---

# 12. 種芋強化コスト

3種類の恒久強化は共通のコスト曲線を使用する。

次の強化Lvを `n` とした場合、

```text
round(n(n+1) / 3)
```

を基準とする。

### 12.1 コスト例

| 強化Lv | 必要種芋 |
|---:|---:|
| 1 | 1 |
| 2 | 2 |
| 3 | 4 |
| 4 | 7 |
| 5 | 10 |
| 6 | 14 |
| 7 | 19 |
| 8 | 24 |
| 9 | 30 |
| 10 | 37 |

---

# 13. 種芋強化画面

各強化項目をカード形式で表示する。

**専用購入ボタンは置かず、項目全体をタップして購入する。**

例：

```text
種芋
12

生産力強化        Lv.3
全生産 +1.5%
NEXT 7 種芋

掘り出し強化      Lv.2
基礎 +0.2 / sec
NEXT 4 種芋

放置強化          Lv.4
最大 10時間
NEXT 10 種芋
```

種芋不足の場合は購入不可表示にする。

# 14. 実績

v2.0.0 で実績機能を追加する。

### 14.1 方針

- 報酬なし
- ゲームバランスへ影響しない
- カテゴリ分けなし
- 隠し実績なし
- 全実績を最初から一覧表示
- ゲーム進行順に並べる

### 14.2 一覧表示

実績名を1行ずつ表示する。

```text
ACHIEVEMENTS

✓ はじめの一掘り
✓ 芋が増えてきた
○ 芋の山
○ 芋の海
✓ 畑仕事入門
○ 畑1の主
○ 最初の種芋
○ 植え直し職人
```

### 14.3 詳細表示

実績をタップすると詳細を表示する。

未達成例：

```text
芋の海

目標
総生産芋 1.000e+9

現在
3.482e+8 / 1.000e+9

進捗
34.8%
```

達成済み例：

```text
芋の海

目標
総生産芋 1.000e+9

達成済み

達成日時
2026/09/21 18:42
```

**v2初回起動日時を達成日時として記録する。**

# 20. 共有機能

ランキングは実装しない。

代わりに、統計画面から現在の記録を共有できるようにする。

共有先は特定アプリへ限定しない。

スマートフォンの標準共有機能を利用し、

- LINE
- X
- メッセージ
- メール
- コピー
- その他対応アプリ

などからユーザーが選択できるようにする。

### 20.1 共有テキスト

140文字以内を意識して短くする。

例：

```text
OIMO HORIHORI 🥔
TOTAL 1.284e+9｜BEST 5.712e+3/s｜REPLANT 3｜ACHIEVEMENT 12/24
#OIMOHORIHORI
```

現在所持芋は共有対象に含めない。

# 21. いも図鑑

# 22. 図鑑基本仕様

初期実装は全20種類。

構成は、

```text
実在する芋の名前を少し変えたもの 15種類
+
ネタ枠 5種類
```

とする。

各いもには、

- ID
- 名前
- 1行フレーバーテキスト
- 発見回数
- 初回発見日時

を持たせる。

レア度は設定しない。

内部レア度も v2.0.0 では持たない。

# 24. 図鑑発見判定

30秒ごとに1回、図鑑発見判定を行う。

1回あたりの発見確率は、

```text
0.035%
```

とする。

発見成功時は、20種類から均等確率で1種類を選ぶ。

### 24.1 発見済みの場合

重複取得を許可する。

重複した場合は、

```text
発見回数 +1
```

とする。

---

# 25. 図鑑の期待値

30秒ごとに0.035%で抽選するため、

おおよそ、

```text
24時間に1個前後
```

の発見を想定する。

20種類は均等抽選・重複ありなので、図鑑コンプリートには長期間を要してよい。

---

# 26. 図鑑のオフライン判定

芋のオフライン生産とは別に扱う。

### 26.1 芋

芋のオフライン生産上限は、

```text
初期8時間
↓
放置強化
↓
最大24時間
```

### 26.2 図鑑

図鑑発見判定は実際の経過時間を使用する。

ただし最大、

```text
24時間分
```

まで抽選する。

そのため、初期状態で芋生産上限が8時間であっても、図鑑は最大24時間分判定される。

---

# 27. オフライン復帰時の図鑑通知

オフライン中にいもを発見した場合は、既存のオフライン復帰カードへ結果を追加する。

例：

```text

獲得芋
+2.184e+4 芋

[ OK ]
```

同じいもを複数回発見した場合はまとめて表示する。

### 27.1 発見0件の場合

図鑑関連の表示行そのものを表示しない。

---

# 28. オンライン中の図鑑通知

オンライン中に新しいいもを発見した場合は、小さい通知のみ表示する。

例：

```text

```

重複の場合も小さい通知でよい。

ゲーム操作を止めるモーダルは表示しない。

```text
種芋強化
```

# 31. セーブデータ互換性

v1.0.0 からの既存セーブデータを可能な限り維持する。

v2.0.0 で追加された項目は、既存セーブロード時に初期値を補完する。

新規項目の例：

- 周回生産量
- REPLANT 回数
- 種芋
- 各恒久強化Lv
- 実績状態
- 達成日時
- 統計
- 図鑑状態
- 各いもの発見回数
- 初回発見日時

セーブデータバージョンを利用して移行処理を行う。
